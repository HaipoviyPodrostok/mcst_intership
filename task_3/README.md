# Задание 3: Реализация прохода SCCP

Реализация алгоритма Sparse Conditional Constant Propagation (SCCP) в виде плагина для LLVM New Pass Manager. Основан на алгоритме SCCP из книги К. Владимирова "Оптимизирующие компиляторы"

## Что делает

Проход анализирует функцию и выполняет:
- **Продвижение констант** — если значение инструкции вычисляется как константа на этапе компиляции, оно заменяется на эту константу
- **Удаление мёртвых веток** — если условие перехода свёрнуто в константу, недостижимые базовые блоки удаляются из функции

### Полурешётка

Каждое SSA-значение находится в одном из трёх состояний:

```
UNDEF  →  CONST  →  OVERDEF
```

Переходы только вниз по решётке (монотонность).

### Структуры данных

- `CfgWL` — рабочий список базовых блоков, которые стали достижимыми
- `SsaWL` — рабочий список инструкций, операнды которых изменили состояние в решётке
- `ExecutedEdges` — множество исполняемых рёбер CFG (пары From → To)
- `LatticeVector` — отображение Value* → состояние в решётке

## Сборка

```bash
cd task_3
cmake -S . -B build && cmake --build build
```

Результат: `build/SccpPass.so`

### Зависимости

- LLVM
- CMake >= 3.14
- Компилятор с поддержкой C++17

## Запуск

### 1. Генерация LLVM IR из тестового файла

```bash
clang -S -emit-llvm -O0 -Xclang -disable-O0-optnone tests/input.c -o tests/input.ll
```

### 2. Запуск прохода

```bash
opt -load-pass-plugin=./build/SccpPass.so -passes=MySCCP tests/input.ll -S -o tests/output.ll
```

### 3. Сравнение результатов

```bash
diff tests/input.ll tests/output.ll
```
